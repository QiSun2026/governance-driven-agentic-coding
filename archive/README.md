# GDAC Archive

This directory contains release artifacts from GDAC versions before v2.0.
They are retained for provenance and comparison; they are not the current
method, runtime, Practice Kit, or public reading site.

The current release starts at the repository [README](../README.md), with the
normative specification under [`method/`](../method/) and the runnable material
under [`practice-kit/`](../practice-kit/).

## v1-series

[`releases/v1-series/`](releases/v1-series/) preserves the original v1.2-v1.5
PDFs and the v1.4 static-site snapshot. The historical artifact bytes are
unchanged. `SHA256SUMS-v1.4.txt` is the original v1.4 manifest, so its relative
layout is intentionally preserved inside the archive.

The complete v1.5 repository remains available at commit
[`39ff3cd`](https://github.com/QiSun2026/governance-driven-agentic-coding/tree/39ff3cd).

Do not use an archived artifact to describe GDAC v2.0 behavior. Historical
material may be cited with its exact version or commit reference.
